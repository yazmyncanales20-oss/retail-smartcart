# Supabase setup (pending)

This project currently runs with fictional data in the browser. The SQL schema in `supabase/schema.sql` is a preparation artifact; it is not applied to any database yet.

1. Sign in to Supabase using the project owner's account and create a separate project for Retail SmartCart.
2. Confirm the selected plan and any cost before creating the project. Prefer the free plan for this academic demo.
3. Open SQL Editor and review `supabase/schema.sql` before running it.
4. Configure Supabase Auth and Row Level Security policies for customer and administrator roles before exposing data through a frontend.
5. Add only the project URL and public anon key to Vercel Preview environment variables. Never put a service-role key in frontend code or GitHub.
6. Keep the app in preview/testing until the owner explicitly approves a release.

No Supabase project has been created or modified by this repository setup.
