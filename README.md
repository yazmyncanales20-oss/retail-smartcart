# Retail SmartCart

Prototipo académico de comercio electrónico de moda, basado en el caso simulado **1.3.1 Análisis de caso simulado**.

## Objetivo del MVP

- Catálogo de ropa con tallas, colores y stock simulado por variante.
- Carrito persistente y resumen transparente de costos.
- Flujo de compra simulado, sin pagos reales.
- Panel administrativo de pedidos, inventario y carritos abandonados.
- Datos ficticios para demostración académica.

## Estado

Desarrollo inicial. Los datos del prototipo se guardan localmente en el navegador. La conexión con Supabase y el despliegue de vista previa se configurarán por separado. No contiene secretos ni credenciales.

## Ejecutar localmente

```bash
npm install
npm run dev
```
